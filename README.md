# FAQ по работе с MongoDB (Используем GUI COMPASS и mongosh)

    По умолчанию MongoDB не настроена для работы с логином и паролем (не требует ) для безопасности необходимо включить эту возможность :
## Запустим предварительно установленный графический клиент Compass и настроим подключение к серверу MongoDB и запустим MongoDB shell

- создадим пользователя с правами администратора для всех баз данных
```
> use admin
> switched to db admin

admin> db.createUser(
  {
    user: "admin", // своё имя (логин) пользователя
  	pwd: passwordPrompt(), // или введите пароль в открытом виде (для старых версий MongoDB)
  	roles: [
    { role: "userAdminAnyDatabase", db: "admin" }, // Позволяет управлять пользователями и ролями
    { role: "readWriteAnyDatabase", db: "admin" } // Даёт право читать и записывать данные в любые базы данных
  ]
  }
)
```
- Убедимся что в списке пользователей servera появился наш пользователь
```
admin> getUsers()
```
## в windows(C:\Program Files\MongoDB\Server\8.2\bin\mongod.conf):
## в Linux(/etc/mongod.conf)
-  открываем для редактирования и в секции security конфигурационного файла нужно добавить или изменить параметр authorization со значением enabled 
```
security:
  authorization: enabled

```
- в секции net конфигурационного файла нужно добавить или изменить параметр  bindIp Это IP-адреса самого сервера, на котором запущен MongoDB. Когда вы указываете их в bindIp, вы говорите MongoDB: «Слушай входящие подключения только на этих сетевых интерфейсах». Через запятую можем указать несколько например bindIp: 127.0.0.1,192.168.1.100:
127.0.0.1 (localhost) → MongoDB принимает подключения только с того же компьютера, где она установлена.
192.168.1.100 → это локальный IP-адрес вашего сервера в локальной сети. Указав его, вы разрешаете другим устройствам в этой же сети подключаться к MongoDB, обращаясь к 192.168.1.100:27017.
!!! YAML чувствителен к отступам → только пробелы, никаких табуляций.
  
```
net:
  port: 27017
  bindIp: 127.0.0.1, 

```
!!! после внесения изменений в .conf необходимо перезапустить service MongoDB

Linux
```
sudo systemctl restart mongod
```

Windows(cmd) cmd запустить от имени Администратора
```
net stop MongoDB
net start MongoDB
```
